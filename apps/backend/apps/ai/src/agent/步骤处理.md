## 处理 tools 部分，先去规范结构话输出契约，让 agent 的返回进行控制

## 问题情况

在 langchain 中 agent 里面使用 tool （自行创建 agent 去单独处理） 但发现 使用 .withStructuredOutput 去进行返回规范 json 格式但会出现

1. DeepSeek Thinking mode 不支持 tool_choice。
2. withStructuredOutput() 默认使用 functionCalling，会自动发送 tool_choice，因此最初返回 400。
3. 改成 jsonMode 后，模型能返回合法 JSON，但不会严格遵守嵌套 Schema：keyExpressions 返回了字符串数组，而不是对象数组；
   ambiguities 字段被省略。

解决办法：

将结构化输出方式改为：method: 'jsonMode'
在 Prompt 中明确完整 JSON 字段和示例。
Schema 对模型常见输出做兼容：
keyExpressions 支持字符串或对象；
缺失数组自动默认 []。

Tool 返回前统一规范化数据结构。
